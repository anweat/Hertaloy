# apps/canvas —— 层积渲染器

一次运行的剖面：**横轴是消息序号**（不是墙钟 —— 内核里没有时钟），
纵向是嵌套，**生命周期就是带的长度**。

```bash
npx serve -l 5178 apps/canvas
```

只依赖 `@nodeflow/scene` 的输出形状，**不 import 任何后端包**（RENDERING.md §8）。

## 为什么是这个形状

上一版画的是浮动气球。它对"嵌套"只给了个弱线索（圈套圈），对"生命周期"
**一条视觉轴都没有** —— 于是质感上不去：好看的信息设计里，美感是结构本身
长出来的，不是贴上去的。

换成层积之后三件事同时落地：

- **嵌套 = 几何包含。** 父带真的包住子带，而这不是排版巧合：父容器必须等所有
  子实例终止才能收口，所以父的生存期**必然**包含子的。图上看到的包含关系
  就是那条不变量本身 —— 已由渲染时的几何断言验过。
- **生命周期 = 长度。** 左端出生、右端终止；还开着的带不收口，虚线拖过
  「现在」界线。
- **执行有宽度。** agent 在沙箱里跑是一段有长度的执行，同步 handler 在一次
  事务里就提交完、只是一个刻点。这个宽度差正是"真的在外面跑"与
  "内核里一瞬间的事"的区别 —— 以前当缺陷记着，现在是个特性。
